Sons Of The Forest — Mod Picker
==============================

วิธีใช้
-------
1. ดับเบิลคลิก  ModPicker.cmd
2. ติ๊กเลือก mod ที่ต้องการ (เอาติ๊กออก = ถอน mod นั้นออก)
3. กด "ติดตั้ง / อัปเดต ตามที่เลือก"  แล้วกด Yes ยืนยัน
4. เปิดเกมผ่าน Steam (หรือกดปุ่ม "เปิดเกม (Steam)")
   - ครั้งแรก RedLoader จะเตรียมไฟล์ประมาณ 1-5 นาที (มีหน้าจอ RedLoader ขึ้น) เป็นเรื่องปกติ
5. ตั้งค่าแต่ละ mod ในเกมได้ที่  เมนูหลัก/หยุดเกม > Mods > (ชื่อ mod) > Settings

ปกป้อง Kelvin (ค่าเลือด)
------------------------
ไฟล์ config ของ mod จะถูกสร้างหลังเปิดเกมครั้งแรก ดังนั้น:
  เปิดเกม 1 ครั้ง > ออกเกม > เปิด ModPicker.cmd > กด "ติดตั้ง / อัปเดต" อีกครั้ง
  โปรแกรมจะตั้งค่าเลือด Kelvin ตามที่กรอกไว้ให้อัตโนมัติ
  (หรือปรับในเกมเองที่ Mods > KelvinCanAttack > Settings > Max Health)

ปุ่มอื่น ๆ
----------
- ปิด mod ชั่วคราว  : เล่นเกมแบบปกติโดยไม่ต้องลบไฟล์ (ใช้ตอนเล่น online กับเพื่อนที่ไม่มี mod
                       หรือตอนเกมอัปเดตแล้ว mod ยังไม่รองรับ) กดอีกครั้งเพื่อเปิดกลับ
- ถอนทั้งหมด        : ลบ RedLoader และ mod ทั้งหมดที่โปรแกรมนี้ติดตั้ง เกมกลับเป็นแบบปกติ
                       (ไฟล์เซฟเกมไม่ถูกแตะ)

Mod ภาษาไทย (สร้างในเครื่องนี้)
-------------------------------
- อยู่หมวด "ภาษา" ใน ModPicker — ติ๊ก "แปลเกมเป็นภาษาไทย" แล้วกดติดตั้ง
- ในเกมตั้งภาษาเป็น English (จะแสดงเป็น "ภาษาไทย")
- ซอร์สโค้ด/คำแปลอยู่ที่ ThaiLanguage\  (คำแปลแยกหมวดใน ThaiLanguage\translations\*.json)
- แก้คำแปลแล้วสร้างแพ็กเกจใหม่: คลิกขวา ThaiLanguage\build.ps1 > Run with PowerShell
  (สคริปต์จะตรวจคำแปล อัปเดต catalog.json ให้อัตโนมัติ แล้วกด "ติดตั้ง / อัปเดต" ใน ModPicker อีกครั้ง)
- ไม่มีการดาวน์โหลด — ฟอนต์ไทยใช้ของ Windows (Leelawadee UI)
- ถ้าเกมอัปเดตแล้วมีข้อความใหม่ ดูได้ที่ Mods\ThaiLanguage\missing.txt ในโฟลเดอร์เกม

Mod ปืนสไนเปอร์ไม้ (สร้างในเครื่องนี้)
-------------------------------------
- อยู่หมวด "อาวุธ (สร้างในเครื่องนี้)" ใน ModPicker
- คราฟ: กิ่งไม้ 10 + ก้อนหินเล็ก 10 = ปืนสไนเปอร์ไม้ / ก้อนหิน 1 = กระสุน 9 มม. 3 นัด / ใบไม้ 3 = กระสุน 9 มม. 1 นัด
- คลิกขวาค้างเพื่อส่องกล้อง (ซูม ~6 เท่า) ใช้กระสุน 9 มม. ดาเมจเท่าปืนพก แม็กละ 5 นัด
- ตั้งค่าได้ที่ Mods\SniperRifle\config.json ในโฟลเดอร์เกม, ซอร์สโค้ดอยู่ที่ SniperRifle\ (build.ps1 = สร้างแพ็กเกจใหม่)
- เล่นออนไลน์: ทุกคนต้องติดตั้งด้วย / ถ้าถอน mod ปืนที่อยู่ในเซฟจะหายไป

Mod Kelvin ตัวที่ 2 + เก็บเครื่องร่อนอัตโนมัติ (สร้างในเครื่องนี้)
--------------------------------------------------------------
- อยู่หมวด "เครื่องมือ (สร้างในเครื่องนี้)" ใน ModPicker
- เข้าโลกประมาณ 15 วินาที เคลวินตัวที่ 2 จะโผล่ข้างหน้า (สีฟ้า มีชื่อ "Kelvin 2" บนหัว) เรียกครั้งเดียวต่อเซฟ
- สั่งงานได้เหมือนเคลวิน (เดินไปหาตัวไหน สั่งตัวนั้น คำสั่งแยกกัน) แต่อมตะ ไม่เหนื่อย/ไม่หิว ไม่กลัว
  ตีแล้วไม่งอน เดิน/ทำงานไว 1.6 เท่า มองเห็นไกล 2 เท่า
- สั่งไปเอาของ (ท่อนไม้ กิ่งไม้ หิน ต้นไม้ อาหาร ฯลฯ) แถวนั้นหมดแล้วก็ยังไปหาไกลขึ้นได้ (5 เท่าของตัวแรก)
- ถือของกลับมาจากที่ไกล (เกิน 60 ม.) จะวาร์ปไปลงใกล้จุดวางของแล้วเดินไปวางเอง (เฉพาะขากลับ ทุก 60 วินาที)
- ร่อนลงพื้นแล้ว ถ้าในกระเป๋าไม่มีเครื่องร่อน จะเก็บอันที่เพิ่งตกให้เอง (มีอยู่แล้ว = ไม่ทำอะไร)
- ตั้งค่าได้ที่ Mods\KelvinTwo\config.json, ซอร์สโค้ดอยู่ที่ KelvinTwo\ (build.ps1 = สร้างแพ็กเกจใหม่)
- เล่นออนไลน์: โฮสต์ต้องติดตั้ง / เพื่อนติดตั้งด้วยเพื่อเห็นสี/ชื่อ และใช้เก็บเครื่องร่อน
- ยังไม่ได้ทดสอบในเกมจริง ลองกับเซฟทดลองก่อน (ตารางเทียบกับเคลวินปกติดูใน KelvinTwo\README-TH.txt)

Mod ตีหินด้วยอีเต้อ ได้หินก้อนใหญ่ (สร้างในเครื่องนี้)
--------------------------------------------------
- อยู่หมวด "เครื่องมือ (สร้างในเครื่องนี้)" ใน ModPicker
- ถืออีเต้อตีหินธรรมชาติ (ก้อนหินใหญ่ หน้าผา ผนังถ้ำ) จะมีหินก้อนใหญ่หล่นข้างหินฝั่งที่ยืน
- ไม่นับพื้นดิน สิ่งก่อสร้างของผู้เล่น (กันปั๊มหินจากกำแพงหิน) ของที่หล่น และหินที่เกมให้ขุดอยู่แล้ว
- ตั้งค่าได้ที่ Mods\PickaxeStone\config.json (ตีกี่ครั้งได้หิน, ได้กี่ก้อน), ซอร์สโค้ดอยู่ที่ PickaxeStone\
- เล่นออนไลน์: คนที่อยากได้ต้องลงเอง / ต้องมีอีเต้อ / ยังไม่ได้ทดสอบในเกมจริง

ความปลอดภัย
-----------
- ตัวโปรแกรมเป็นสคริปต์ข้อความล้วน (ModPicker.ps1) เปิดอ่านด้วย Notepad ได้ทุกบรรทัด
  ไม่มีไฟล์ .exe แปลกปลอม และไม่ขอสิทธิ์ Administrator
- แหล่งดาวน์โหลดมีแค่ 2 แห่ง:
    RedLoader : https://github.com/ToniMacaroni/RedLoader (GitHub ของผู้สร้าง RedLoader)
    Mod       : https://sotf-mods.com (เว็บ mod หลักของเกมนี้ / เลือกเฉพาะผู้สร้างที่ verified เป็นหลัก)
- ทุกไฟล์ถูกล็อกค่า SHA256 ไว้ใน catalog.json — ถ้าไฟล์ถูกเปลี่ยนแม้ 1 byte จะไม่ติดตั้ง
- สแกนด้วย Windows Defender ก่อนติดตั้งทุกครั้ง (ถ้าพบภัยคุกคามจะยกเลิกทันที)
- ตรวจไฟล์ใน zip ก่อนแตก: อนุญาตเฉพาะโฟลเดอร์ Mods\ Libs\ _Redloader\ และไฟล์ชนิด
  .dll .json .xml .ini .png .mp3 .obj เท่านั้น (ห้าม .exe .bat .ps1 ฯลฯ และห้าม path หลุดออกนอกโฟลเดอร์เกม)
- ไฟล์เดิมที่ถูกเขียนทับจะถูกสำรองไว้ที่ backup\  และบันทึกการทำงานอยู่ที่ logs\
- หมายเหตุ: mod ทุกตัวคือโค้ด (.dll) ที่รันในเกม มาตรการข้างบนช่วยลดความเสี่ยงได้มาก
  แต่ไม่มีวิธีใดรับประกันได้ 100% — จึงเลือกเฉพาะ mod ยอดนิยมจากผู้สร้างที่ verified

โครงสร้างโฟลเดอร์
-----------------
ModPicker.cmd     ตัวเปิดโปรแกรม
ModPicker.ps1     ตัวโปรแกรม (PowerShell + หน้าต่าง Windows Forms)
catalog.json      รายการ mod + เวอร์ชัน + ค่า SHA256 ที่ล็อกไว้
ThaiLanguage\     ซอร์สโค้ด + คำแปลของ mod ภาษาไทย (build.ps1 = สร้างแพ็กเกจใหม่)
SniperRifle\      ซอร์สโค้ดของ mod ปืนสไนเปอร์ไม้ (build.ps1 = สร้างแพ็กเกจใหม่)
KelvinTwo\        ซอร์สโค้ดของ mod เคลวินตัวที่ 2 + เก็บเครื่องร่อน (build.ps1 = สร้างแพ็กเกจใหม่)
PickaxeStone\     ซอร์สโค้ดของ mod ตีหินด้วยอีเต้อได้หินก้อนใหญ่ (build.ps1 = สร้างแพ็กเกจใหม่)
tools\            Install-LocalMod.ps1 = ติดตั้ง mod ที่ build ในเครื่องโดยไม่ต้องเปิด ModPicker
packages\         ไฟล์ mod ที่ตรวจแล้ว (ติดตั้งได้แม้ไม่มีเน็ต / ถ้าหายจะดาวน์โหลดใหม่และตรวจซ้ำ)
state\            รายการไฟล์ที่ติดตั้งไปแล้ว (ใช้ตอนถอนการติดตั้ง)
backup\           ไฟล์เดิมที่ถูกสำรองไว้
logs\             บันทึกการติดตั้ง
