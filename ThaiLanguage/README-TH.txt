Thai Language — mod ภาษาไทยสำหรับ Sons Of The Forest
=====================================================

ทำอะไรบ้าง
----------
- แปลข้อความที่เกมรองรับการแปลทั้งหมด (~1,300 ข้อความ): เมนู ตั้งค่า ไอเทม ปุ่มกด คำแนะนำ
  คำใบ้ คำบรรยายบทพูด คำสั่ง Kelvin สูตรอาหาร ฯลฯ
- เพิ่มฟอนต์ไทยจาก Windows (Leelawadee UI) เป็นฟอนต์สำรองของเกม — ไม่ต้องติดตั้งฟอนต์เพิ่ม
- จัดตำแหน่งสระบน/สระล่าง/วรรณยุกต์ให้ถูกต้อง (เช่น "ที่" "ญี่ปุ่น" "ผู้")
- ตัดคำไทยให้ขึ้นบรรทัดใหม่ตรงรอยต่อคำ (ใช้ตัวตัดคำภาษาไทยของ Windows)
- ใช้ได้ทั้งเล่นคนเดียวและเล่นออนไลน์ (เปลี่ยนแค่ข้อความในเครื่องคุณ)

วิธีใช้
-------
1. ติดตั้งผ่าน ModPicker (ติ๊ก "แปลเกมเป็นภาษาไทย")
2. ในเกมตั้งภาษาเป็น English — ในเมนูจะแสดงเป็น "ภาษาไทย"
   (ถ้าตั้งเป็นภาษาอื่น เกมจะแสดงภาษานั้นตามปกติ)

ข้อจำกัด
--------
- โน้ต อีเมล หนังสือพิมพ์ ป้ายต่าง ๆ ในเกมเป็นรูปภาพ จึงยังเป็นภาษาอังกฤษ
- ข้อความที่เกมเขียนตายตัวไว้ใน UI (ไม่ผ่านระบบแปล) จะแปลได้เฉพาะที่ตรงกับคำที่รู้จัก
- เมนูของ mod อื่น ๆ เป็นภาษาของผู้สร้าง mod นั้น

แก้คำแปลเอง
-----------
ไฟล์ Mods\ThaiLanguage\th.json (เปิดด้วย Notepad ได้)
- แก้เฉพาะข้อความด้านขวา ห้ามแก้ชื่อคีย์ด้านซ้าย
- ต้องคง {0} {label} {BUTTON.Take} และ <color=...></color> ไว้เหมือนเดิม
- บันทึกเป็น UTF-8 แล้วเปิดเกมใหม่
หมายเหตุ: ถ้ากด "ติดตั้ง / อัปเดต" ใหม่ใน ModPicker ไฟล์นี้จะถูกเขียนทับ — เก็บสำเนาไว้ก่อน

ไฟล์รายงาน (สร้างขึ้นตอนเล่น)
------------------------------
missing.txt       ข้อความในเกมที่ยังไม่มีคำแปล (เช่น หลังเกมอัปเดตเพิ่มข้อความใหม่)
untranslated.txt  ข้อความภาษาอังกฤษที่เห็นบนจอแต่ไม่ได้มาจากระบบแปลของเกม

ตั้งค่า: config.json (เปลี่ยนฟอนต์ ขนาดตัวอักษร ปิด/เปิดฟีเจอร์)
ถ้ามีปัญหา: ดู _Redloader\Latest.log ในโฟลเดอร์เกม (ค้นคำว่า ThaiLanguage)
