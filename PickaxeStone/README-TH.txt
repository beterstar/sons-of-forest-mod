Pickaxe Stone — ตีหินด้วยอีเต้อแล้วได้หินก้อนใหญ่ สำหรับ Sons Of The Forest
=========================================================================

ทำอะไร
------
ถืออีเต้อ (Pickaxe) แล้วตีหินก้อนใหญ่ หน้าผา หรือหินในถ้ำ
จะมี "หินก้อนใหญ่" (ที่ใช้สร้างฐาน) หล่นออกมาข้างหินฝั่งที่คุณยืน เดินไปเก็บได้เลย
ค่าเริ่มต้น: ตี 1 ครั้ง ได้ 1 ก้อน (ปรับได้ใน config.json)

อะไรนับ / ไม่นับ
---------------
นับ    : หินธรรมชาติในแมพที่เกมจัดว่าเป็นพื้นผิว "หิน" (ก้อนหินใหญ่ หน้าผา ผนังถ้ำ)
ไม่นับ  : พื้นดิน (ตีพื้นไม่ได้หิน), สิ่งก่อสร้างที่ผู้เล่นสร้าง (รวมกำแพงหิน กันปั๊มหินไม่จำกัด),
         ของที่วาง/คราฟ, ของที่หล่นอยู่, สัตว์/คน, หินแบบที่เกมให้ขุดอยู่แล้ว (ใช้ระบบเดิมของเกม)
         และอาวุธอื่นที่ไม่ใช่อีเต้อ

เล่นกับเพื่อน (co-op)
--------------------
- แต่ละคนที่อยากได้ฟีเจอร์นี้ต้องลง mod เอง (นับเฉพาะการตีของตัวเอง)
- หินที่หล่นใช้ระบบหล่นของของเกม เพื่อนเห็นและเก็บได้

ติดตั้ง
------
เปิด ModPicker.cmd > หมวด "เครื่องมือ (สร้างในเครื่องนี้)" > ติ๊ก "ตีหินด้วยอีเต้อ ได้หินก้อนใหญ่" > ติดตั้ง
(หรือก๊อป PickaxeStone.dll + โฟลเดอร์ PickaxeStone ไปไว้ใน <โฟลเดอร์เกม>\Mods\)

ตั้งค่า (Mods\PickaxeStone\config.json)
-------------------------------------
- enabled               : เปิด/ปิด
- hitsPerDrop           : ตีกี่ครั้งได้หิน 1 รอบ (1 = ทุกครั้ง)
- stonesPerDrop         : ได้กี่ก้อนต่อรอบ (1-5)
- minSecondsBetweenHits : กันนับซ้ำในการเหวี่ยงครั้งเดียว
- dropItemId            : 0 = หินก้อนใหญ่ หรือใส่เลขไอเทมอื่น

ข้อจำกัดที่ควรรู้
---------------
- ยังไม่ได้ทดสอบในเกมจริง (คอมไพล์กับไฟล์เกมจริงผ่าน + เทสต์ offline ผ่าน) ลองกับเซฟทดลองก่อน
- ต้องมีอีเต้อในเกมก่อน (mod ไม่ได้เพิ่มอีเต้อให้)
- ถ้าตีแล้วไม่มีหินหล่น: เกมอาจไม่ได้จัดหินก้อนนั้นเป็นพื้นผิว "หิน" ดู log ด้านล่าง
- ตีหินเยอะๆ หินที่หล่นจะอยู่ในโลกและถูกบันทึกลงเซฟเหมือนของที่หล่นทั่วไป

มีปัญหา
-------
ดู _Redloader\Latest.log ในโฟลเดอร์เกม ค้นคำว่า PickaxeStone
- การตีด้วยอีเต้อช่วงแรกๆ (ประมาณ 4 ครั้ง) จะเขียนว่าตีโดนอะไร และนับหรือไม่นับเพราะอะไร เช่น
    pickaxe hit 'Boulder_03': rock                    <- นับ ได้หิน
    pickaxe hit 'Cliff_A': surface Default            <- เกมไม่ได้จัดว่าเป็นหิน
    pickaxe hit 'RockWall': game's own mineable rock  <- หินที่เกมให้ขุดเองอยู่แล้ว
- ถ้าได้หินครั้งแรกจะมีบรรทัด "first drop"
- ถ้าไม่มีบรรทัด "pickaxe hit" เลย แปลว่า mod ไม่เห็นการตีของอีเต้อ (ส่ง log มาให้ดูได้)
